# Vue Page Generator
> Vue 화면/페이지 개발은 `frontend-design` 스킬을 사용한다.
## 절차
1. `frontend-design` 스킬 호출
2. 생성된 코드를 `adlex-dashboard/src/views/{Page}View.vue` 에 저장
3. 필요 시 `src/api/{domain}.ts`, `src/stores/{domain}.ts` 병행 생성
